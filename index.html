HOW TO REPLACE MOCK DATA WITH LIVE API

  1. In mockData.js, replace triggerNextScan() with a fetch('http://localhost:5000/api/scan/next', { method: 'POST' }) call.
  2. Or set up a WebSocket connection: const ws = new WebSocket('ws://localhost:5000/ws/spectrum');
  3. Call window.mockData.notifyListeners() whenever new backend data arrives. The entire UI will re-render automatically!
